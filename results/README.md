# `results/` — benchmark outputs and paper figures

This tree holds committed, reviewer-facing artifacts:

```
results/
├── paper/               # committed CSVs that back every paper figure/table
│   ├── scf/             # Segmented Cuckoo Filter benches
│   │   ├── load_factor.csv
│   │   ├── insert_throughput.csv
│   │   ├── lookup_throughput.csv
│   │   ├── delete_throughput.csv
│   │   ├── eviction.csv
│   │   ├── degree_distribution.csv
│   │   └── fpr/         # one CSV per (arity, n, b) config
│   └── pir/             # Incremental-Keyword-PIR benches (Phase B/C)
│       ├── setup_latency.csv
│       ├── query_latency.csv
│       ├── insert_cost.csv
│       ├── delete_cost.csv
│       └── full_rebuild_vs_incremental.csv
├── plots/               # committed PNG/SVG figures regenerated by `just plots`
└── SCHEMA.md            # CSV column definitions for every bench output
```

Transient per-run bench output lives in `crates/<crate>/results/` and is
`.gitignore`d. `just bench-scf-portable` / `just bench-pir-portable` copy
the canonical subset into `results/paper/` after each run.

See [`SCHEMA.md`](SCHEMA.md) for column definitions and
[`../docs/BENCHMARKS.md`](../docs/BENCHMARKS.md) for the methodology.
